# feat: 흑백 템플릿 트레이 아이콘 — 메뉴바에 맡긴다

**Goal Capsule** — 트레이 아이콘을 macOS **템플릿 이미지**로 바꿔 다크/라이트
메뉴바에 자동 적응하게 한다. 색을 우리가 정하지 않고 OS가 정한다.

- **출처** — `TODO.md` 후속 "흑백 템플릿 트레이 아이콘"과 2026-09-01 사용자 지시.
- **실행 프로필** — 브랜치 `feat/template-tray-icon-01`. 로직 변경이 없어 테스트는
  기존 러너 통과 확인만, 검증은 수동(메뉴바 육안).

## KTD1 — 실루엣은 새로 그리지 않고 지금 아이콘에서 뽑는다

템플릿 이미지의 규칙은 "검정 + 알파"다. 지금 `tray.png`(58×44 RGBA, 스캐폴딩 때
넣은 컬러 펭귄)의 **알파 채널이 곧 실루엣**이므로, 색이 있는 픽셀을 전부 검정으로
바꾸고 알파를 유지하면 같은 모양의 템플릿 아이콘이 된다 (PIL로 변환, 산출물만
커밋). 새 실루엣을 그리는 것은 모양 논의를 여는 일이라 하지 않는다 — 모양이
마음에 안 들면 그때 별건으로 연다.

**크기는 메뉴바 규격에 맞춘다**: 세로 44px(@2x 기준 22pt)는 이미 맞다. 가로
58px은 비표준이지만 macOS가 비율대로 그리므로 그대로 둔다 — 여백 손질이 필요해
보이면 수동 확인 단계에서 판단한다.

## KTD2 — 코드 변경은 두 줄이다

`lib.rs`의 `.icon_as_template(false)` → `true`, 그리고 아이콘 파일 교체(같은
경로 `icons/tray.png` 덮어쓰기 — `include_bytes!` 경로 불변). 트레이 생성
타이밍·이벤트 배선은 건드리지 않는다 — `CLAUDE.md` 함정 목록의 트레이 규칙
(setup 동기 생성, positioner 우선 호출)은 그대로 지나간다.
